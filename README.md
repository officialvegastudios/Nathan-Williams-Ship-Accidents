 Ship Accidents Analysis

 Purpose

This repository contains a statistical analysis of ship accident data completed as part of SRM 611 Project 2. The analysis examines whether a ship's exposure score is related to the number of monthly health-related accidents while accounting for the ship's construction era.

 Data

The analysis uses the Ship Accidents dataset. The dataset contains information about ships, including the number of accidents, exposure, and construction characteristics.


 Repository Files

- `README.md` describes the purpose, data source, and organization of the repository.
- `ship_accidents_analysis.R` contains the R code used to import, clean, summarize, and analyze the ship accident data.
